# 任务四：可控纠错记忆验收

完成日期：2026-10-07。

核对页的“核对后记住标签”现在默认不勾选。用户核对原件后主动勾选并下载 Excel，才会把“原文标签 → 业务字段”保存到本机。修改字段值或改用另一份单据候选值时会自动取消勾选，防止旧标签随修正结果误存。服务端还要求显式确认、有效业务字段及非空审核值；标签必须具有字段标签特征，且不得包含当前审核表中的业务值。

AI 设置下新增“已确认的纠错记忆”：可查看标签映射、撤销单条映射，并可主动批准或撤销固定的箱型格式规则。当前允许的格式规则只有 `20DV → 20GP`、`20DC → 20GP`、`40HC → 40HQ`；不从单票业务值自动推断新规则。撤销后，后续提取不再使用该映射或格式规则。

仓库跟踪的 `data/field_aliases.json` 保留为审核过的初始标签表。新增、撤销和格式规则写入本机 `data/approved_memory.json`，该文件已加入 Git 忽略列表。文件仅包含字段名、标签、启用或撤销状态以及上述箱型代码；不保存提单号、船名、港口、客户单据或 API Key。这些记忆作为下次 AI 提取的标签参考或确定性的箱型规范，不会训练模型。

验收：Python 69 项测试通过；前端 6 项检查通过；`memory.js`、`review.js`、`app.js` 语法检查通过；本机 HTTP 用例覆盖了查看、增加和撤销格式规则；单元测试覆盖了未确认不保存、确认后可查看和撤销、业务值不入库，以及撤销格式规则后的结果恢复。
