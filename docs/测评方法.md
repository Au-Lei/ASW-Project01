# 新单据盲测方法

把未用于调规则的真实单据和标准答案保存在项目目录之外，不要上传到 GitHub。

在你自己的私有目录建立 `holdout.json`，内容格式如下，路径可写成绝对路径或相对清单的路径：

```json
{
  "cases": [
    {
      "id": "case-001",
      "documents": [
        {"path": "notice.pdf", "role": "入货通知"},
        {"path": "entrustment.docx", "role": "订舱委托书"}
      ],
      "expected": {
        "bl_number": "EXAMPLE123",
        "vessel": "EXAMPLE VESSEL",
        "voyage": "001W",
        "sailing_date": "10.1",
        "containers": "1X40HC",
        "station": "",
        "destination": "EXAMPLE PORT",
        "origin": "QD"
      }
    }
  ]
}
```

在项目目录运行 `python evaluate_cases.py C:\private\holdout.json`，程序会逐票显示不一致字段、读取质量提示、整票全对数以及漏填与误填数量。

每轮修改前后都用同一批盲测票对比，但不要根据盲测票逐条添加专用规则；遇到新问题，应另放入开发集，并保留下一批未见过的票继续验证。

这个脚本目前只评估规则模式；AI 模式尚未接入命令行测评，不能把本脚本的结果当作 AI 模式的准确率。
