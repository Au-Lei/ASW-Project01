## 页面限制与费用

当前 `deepseek-flash` 路径会将每份 PDF 最多 3 页渲染成 JPEG 页面图像发送给模型；扫描件无文字层时仍可提取。超过 3 页会显示核对提示。每次发送图像时均显示“可能产生额外图像费用”。`deepseek-v4-pro` 只支持文字输入，不能据此验收扫描图像。上述模型能力与按 token 计费方式见 [DeepSeek 视觉文档](https://api-docs.deepseek.com/guides/vision/)和[模型及价格](https://api-docs.deepseek.com/quick_start/pricing/)；单票实际扣费应以厂商账单为准，本项目当前不计算具体金额。
