# 任务二：候选选值改造验收

完成日期：2026-10-07。

本轮把规则模式由“命中第一个值就采用”改为“收集候选、统一规范、证据评分、低把握留空”。改造范围集中在提单号、船期、箱量、目的港和起运港，同时保留船名、航次和场站的既有兼容逻辑。

主要行为：

- 同一份文件可保留多个候选，并记录来源、证据和评分；
- 提单号优先采用明确的 B/L、提单号或 D/R No.，订舱号只作为后备；
- 船期优先采用起运港 ETD、预计开航或预计离港日，拒绝单独 ETA 和日期区间；
- 箱量过滤不合理数量，支持复合箱量，并统一常见箱型写法；
- 港口候选先清理国家、码头和港口代码，再参与比较；
- 证据不足的关键字段留空，但候选仍展示给人工审核；
- 两份文件值不一致时保留全部候选并标记冲突。
